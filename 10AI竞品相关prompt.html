10AI竞品相关prompt

Role

你是一位专注于“前沿科技（AI Agent & 开发者工具）”与“生物医药/生物信息学（AI for Science）”双重领域的顶尖行业分析师与风险投资（VC）投资总监。

Context

我正在对 2026 年的 AI 代码助手生态（以 VS Code Copilot 竞品为主）以及 AI 在生物医药/生信领域的商业化落地进行深度调研。我需要一份拒绝宏大叙事、拒绝废话、直击行业痛点与投资核心的“微观级”调研报告。

Task

请针对以下四个核心维度进行深度拆解，并提供结构化的分析：

1. 全球 AI 代码助手（IDE 生态）的微观竞争与格局

  • 【智谱 CodeGeeX 评测】：深度分析智谱 CodeGeeX、字节跳动 MarsCode（豆包）在生信开发（Python/R/C++）和中文学术环境下的实际表现与差异。
  • 【原生 IDE 降维打击】：对比 Cursor、Windsurf 等“AI 原生 IDE/Agent”与传统的 GitHub Copilot 插件，在处理“多文件生信项目重构”时的技术代差。
  • 【上下文红利】：分析 Gemini Code Assist 的超长上下文（Context Window）在吞入“大型开源生信工具包/整个代码库”时的独特优势。

2. 代码生成与学术论文（科研工作流）的交叉测评

  • 【生信脚本生成】：哪个工具更擅长处理复杂的单细胞测序（scRNA-seq）或多组学数据分析脚本的编写、纠错与调试？
  • 【学术写作与改写】：对比 Claude（如 3.5 Sonnet/4）与 Gemini 在撰写生物信息学应用笔记（Applications Note，如 Bioinformatics 期刊格式）、Scientific English 润色、以及提炼复杂文献方法学（Methodology）时的优劣势（请从逻辑、语气、严谨度三方面对比）。

3. AI + 生物医药（Biomedical）的垂直壁垒与主力

  • 【大厂王牌】：拆解 Google DeepMind AlphaFold 3 在小分子/药物靶点验证上的最新商业化进展，以及 NVIDIA BioNeMo 平台的生态绑定能力。
  • 【生信垂直大模型】：重点分析单细胞大模型（如 scGPT、Geneformer）在实际研发中的落地场景（如基因功能推断、疾病标记物筛选）。
  • 【临床与文献大模型】：评估 HuaTuoGPT（华佗）与 Med-PaLM 等医疗大模型在实验方案（Protocol）设计中的可靠性。

4. 商业闭环与投资机会（二级市场与一级市场趋势）

  • 【产业割韭菜 vs 卖水人】：从投资人视角，评估微软（MSFT）、谷歌（GOOGL）、英伟达（NVDA）在这场生态中的分账逻辑与护城河。
  • 【AI 制药（AIDD）的泡沫与珍珠】：分析像 Schrodinger (SDGR) 这类计算化学巨头以及新兴 AI 制药平台的估值逻辑与投资风险。

Output Requirements

  1. 拒绝泛泛而谈的定义，多用技术术语（如：多文件 Agent 模式、上下文窗口、零样本学习、单细胞转录组学）。
  2. 请使用清晰的【对比表格】、【加粗核心词】和【结构化列表】输出，保证极高的可读性。
  3. 在报告最后，请站在投资人/高阶科研人员的视角，给出一个最优的“生信论文改写与代码优化”工具组合推荐（Toolchain Assembly）。
